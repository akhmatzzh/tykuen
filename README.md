# Тыкуэн

Тыкуэн — молодежная PWA-платформа для жителей Кабардино-Балкарской Республики. Пользователи смогут продавать вещи, отдавать их бесплатно, обмениваться ими и предлагать услуги с договоренностью напрямую.

## Основные возможности

- Регистрация и вход по электронной почте и паролю.
- Профиль с именем и населенным пунктом КБР.
- Объявления о продаже, обмене и бесплатной передаче вещей.
- Отдельный раздел услуг.
- До пяти фотографий на объявление.
- Поиск, фильтры, свежая лента и избранное.
- Личные текстовые чаты с emoji и статусом прочтения.
- Жалобы на объявления и пользователей.
- Адаптивный интерфейс и установка как PWA.

Сделки организуются напрямую между пользователями. Платформа не обрабатывает платежи и не организует доставку.

## Технологический стек

- React, TypeScript, Vite
- Supabase: PostgreSQL, Auth, Storage, Realtime
- PWA
- Git и GitHub
