# Тыкуэн

Тыкуэн — молодежная PWA-платформа для жителей Кабардино-Балкарской Республики. Пользователи смогут продавать вещи, отдавать их бесплатно, обмениваться ими и предлагать услуги с договоренностью напрямую.

## Стек

- React и TypeScript
- Vite
- Supabase: PostgreSQL, Auth, Storage и Realtime
- PWA
- Vitest и Testing Library

## Требования

- Node.js 20.19+ или 22.12+
- npm

## Локальный запуск

```bash
npm install
npm run dev
```

## Проверки

```bash
npm run lint
npm run typecheck
npm run test
npm run build
```

## Структура

- `src/app` — приложение и его страницы.
- `src/components` — общие интерфейсные компоненты.
- `src/features` — функциональные модули.
- `src/pages` — страницы приложения.
- `src/hooks` — повторно используемые хуки.
- `src/lib` — общие клиенты и библиотеки.
- `src/services` — интеграции и работа с данными.
- `src/types` — общие типы TypeScript.
- `src/styles` — стили.
- `src/test` — настройки тестовой среды.
- `docs` — архитектура и технические решения.
- `tests` — дополнительные модульные и интеграционные тесты.

## Текущий этап

В репозитории находится стартовый адаптивный интерфейс с демонстрационными объявлениями, поиском и фильтрами на стороне клиента. Аутентификация, Supabase, публикация объявлений и реальные чаты ещё не подключены.
