# Архитектура Тыкуэн

## Назначение

Тыкуэн — молодежная PWA-платформа для объявлений о продаже, бесплатной передаче и обмене вещей, а также для предложений услуг в Кабардино-Балкарской Республике.

## Планируемые технологии

- React и TypeScript для интерфейса.
- Vite для разработки и сборки.
- Supabase Auth для аутентификации.
- PostgreSQL для хранения данных.
- Supabase Storage для изображений.
- Supabase Realtime для обновления чатов.
- PWA для установки приложения и базовых возможностей веб-приложения.

## Структура исходного кода

- `src/app` — конфигурация приложения и маршрутизация.
- `src/components` — общие интерфейсные компоненты.
- `src/features` — функциональные модули предметной области.
- `src/pages` — страницы приложения.
- `src/hooks` — общие React-хуки.
- `src/lib` — клиенты и вспомогательные библиотеки.
- `src/services` — взаимодействие с внешними сервисами.
- `src/types` — общие типы TypeScript.
- `src/styles` — глобальные стили и дизайн-токены.
- `docs` — архитектура и технические решения.
- `tests` — модульные и интеграционные тесты.

Эта схема является исходным планом. Фактическая структура уточняется при реализации.
