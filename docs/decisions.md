# Технические решения

## 1. Клиентское приложение

**Решение:** React, TypeScript и Vite.

**Причина:** этот стек подходит для адаптивного веб-приложения с компонентным интерфейсом и типизацией.

## 2. Backend и данные

**Решение:** Supabase с PostgreSQL, Auth, Storage и Realtime.

**Причина:** сервис предоставляет базу данных, аутентификацию, хранение изображений и возможности обновления чатов в рамках единой платформы.

## 3. Формат приложения

**Решение:** адаптивный сайт с поддержкой PWA.

**Причина:** пользователи смогут пользоваться платформой с мобильных устройств и устанавливать её на поддерживаемые устройства.

## 4. Работа с объявлениями и сделками

**Решение:** платформа помогает пользователям находить друг друга и договариваться напрямую; встроенные платежи и доставка не входят в проект.

**Причина:** это соответствует локальному формату сервиса и ограничивает начальный объём разработки.

## 5. Соглашения команды

**Решение:** именованные ветки, понятные сообщения коммитов, Pull Request и единый стиль TypeScript.

**Причина:** такие правила делают историю изменений понятнее и упрощают проверку кода.
